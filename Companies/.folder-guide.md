# /Companies

Standing knowledge base — one file per company, e.g. `k-electric.md`, `engro.md`. Not per-episode.

Updated whenever an episode's research touches a company, so the next episode that mentions the same company starts from what's already known instead of re-researching from zero. Include: founding/history, ownership, key figures, financials touched on previously, controversies, and a running list of which episodes have referenced this company.
