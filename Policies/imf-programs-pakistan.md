# Standing Knowledge — Pakistan's IMF Programs

Contributed by: EP001 ("1998: The Year Pakistan Went Broke on Purpose")

## Summary

Pakistan has a long history of repeated IMF programs (the "IMF Loop" topic idea in the database references this directly). This file currently holds only the 1997-99 program in detail; expand it whenever a future episode researches another IMF program so the full history accumulates in one place instead of being re-researched each time.

## 1997-99 program (documented so far)

- October 1997: Three-year Enhanced Structural Adjustment Facility / Extended Fund Facility (ESAF/EFF) program agreed, targeting the current account deficit and reserve levels.
- Early 1998: Six-month review — IMF assessed performance positively, program continued.
- May 1998: Nuclear tests and resulting sanctions disrupted the program's trajectory.
- 14 January 1999: Second annual ESAF arrangement approved; ~$575 million disbursed.
- Late January 1999: Paris Club agreed to reschedule debt service due 1998-99 through first half of 2000-01; London Club provided parallel relief.
