# /Research

One file per episode: `EP###_slug-name.md`, built from `Templates/research-brief.md` by the Research Assistant skill.

This folder holds episode-specific research. Standing knowledge that's reusable across episodes (a company's history, an ongoing policy, a sector's structure) belongs in `/Companies`, `/Economy`, `/Policies`, or `/Industries` instead — the Research Assistant skill should update those files, not just this one, when it gathers reusable background.
