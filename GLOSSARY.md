# Glossary — Approved Bilingual Terminology

Keep terminology consistent across episodes. When a script introduces a new recurring term (economic, political, or cultural), add it here so future episodes use the same rendering.

Rule of thumb: keep a Roman Urdu word when it carries more weight or familiarity than its English equivalent (e.g. "Awam" over "the public"); switch to English when the English term is what viewers actually hear in the news (e.g. "inflation," not "mehngai," when discussing the CPI figure specifically).

## Economy & Finance

| Term | Approved rendering | Notes |
|---|---|---|
| Mehngai | Inflation / mehngai (used interchangeably) | Use "mehngai" in narration for the lived experience, "inflation" when citing the CPI number |
| Munafa | Profit | Use "munafa" only in dialogue/quotes, "profit" in narration |
| Sarkar / Hukumat | Government | Use "government" in narration; "sarkar" fine in casual asides |
| Awam | The public / ordinary people | Prefer "awam" — carries the right tone |
| Circular Debt | Circular debt (gardishi qarza) | Define once per episode it appears in: unpaid bills piling up across the power sector |
| SBP | State Bank of Pakistan (SBP) | Spell out on first use per episode |
| GDP | GDP (mulki paidawar) | Define once: total value of everything the country produces in a year |

## Policy & Government

| Term | Approved rendering | Notes |
|---|---|---|
| IMF Program | IMF program / IMF deal | Avoid "IMF loan" alone — usually a program with conditions, not a simple loan |
| Subsidy | Subsidy (sabsidi) | Define once: government paying part of a cost so the public pays less |
| Privatization | Privatization (nijkari) | Neutral rendering — avoid "sell-off" unless quoting a critic |

## How to extend this file
